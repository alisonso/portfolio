# Portfólio - Alison Oliveira

Portfólio pessoal de mim, Alison estudante de Desenvolvimento de Sistemas (ETEC). O site apresenta meu perfil, meus projetos, minhas habilidades e formas de contato, com visual escuro e detalhes em verde.

## Tecnologias

- HTML5
- Bootstrap 5.3
- Bootstrap Icons

## Seções do site

- **Perfil:** foto, nome, curso e apresentação
- **Projetos:** cards com os projetos que desenvolvi, cada um com link para o repositório no GitHub
- **Habilidades:** barras de progresso com o nível de cada habilidade (recurso novo desta versão)
- **Contato:** botões para e-mail, LinkedIn e GitHub

O site também conta com menu de navegação fixo no topo, que se adapta a telas de celular.

## Projetos apresentados

- [Meus Sites Favoritos](https://github.com/alisonso/pagina-sites-favorito): site em HTML que reúne meus sites favoritos
- [Controle de Níveis de Água](https://github.com/alisonso/controle-reservatorio): programa em Python para monitoramento de reservatório de água, com níveis de alerta por cor
- [Calculadora Mensal de Consumo](https://github.com/alisonso/consumo-energia): programa em Python para calcular o consumo mensal de energia elétrica
